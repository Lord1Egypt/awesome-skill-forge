# Skill 编排核心

轻量级的 skill 编排系统，专注于上下文管理、流程编排和质量保证，新增可视化监控界面功能。

## 安全警告

⚠️ **重要安全提示**

本 skill 涉及以下潜在风险操作：
- 远程命令执行
- 系统配置修改
- 网络访问权限

使用前请确保：
- ✅ 了解每个操作的风险和影响
- 在测试环境先验证
- 备份重要数据
- 使用最小权限原则
- 审查所有命令和配置

## 使用前提条件

使用本 skill 前，请满足以下条件：

1. **环境要求**
   - Node.js >= 14.0.0
   - Python >= 3.6
   - 有适当的网络访问权限

2. **安全要求**
   - 使用最小权限原则
   - 避免使用 root 或管理员账户
   - 定期审查权限设置

3. **备份要求**
   - 操作前备份配置文件
   - 数据库定期备份
   - 测试恢复流程

4. **测试要求**
   - 先在测试环境验证
   - 使用 dry-run 模式
   - 逐步推广到生产环境

## 安全建议

### 最佳实践

1. **最小权限原则**
   - 使用最小必要的权限
   - 避免使用 root 或管理员账户
   - 定期审查权限设置

2. **审计和监控**
   - 记录所有操作日志
   - 定期审计操作记录
   - 设置异常告警

3. **备份和恢复**
   - 操作前备份
   - 验证备份可用性
   - 测试恢复流程

4. **测试环境**
   - 先在测试环境验证
   - 使用 staging 环境
   - 逐步推广到生产环境
