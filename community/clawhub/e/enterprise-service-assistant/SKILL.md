### 核心逻辑

#### 1. 查询客户档案

```python
def query_customer(unit_no=None, tenant_name=None, contract_no=None):
    wb = openpyxl.load_workbook('[请配置你的Excel文件路径]')
    ws = wb['👨客户管理👨']
    headers = [cell.value for cell in ws[1]]
    for row in ws.iter_rows(min_row=2, values_only=True):
        if unit_no and row[5] == unit_no:
            return dict(zip(headers, row))
        if tenant_name and tenant_name in str(row[6]):
            return dict(zip(headers, row))
        if contract_no and row[4] == contract_no:
            return dict(zip(headers, row))
    return None
```

读取以下工作表，按`单元号`或`租户名`关联聚合：

| 静默处理 | 1-7天 | 仅记录，不推送 | 无 |
| 提醒通知 | 8-30天 | 推送催缴通知 | 财务、企服 |
| 升级处理 | 31天+ | @all通知，升级处理 | @all |

### 催缴话术模板

**首次逾期**：`您有费用已逾期{X}天，请尽快处理，避免产生滞纳金。`

**多次逾期**：`您已多次逾期，请高度重视，尽快安排缴纳。`

**费用类型话术**：
- 管理费：`物业管理费是园区正常运营的基础，请按时缴纳。`
- 电费：`电费欠费可能影响用电服务，请尽快缴纳。`
- 租金：`租金是合同义务，请按时履行。`

### 核心逻辑

#### 逾期天数计算

```python
today = datetime.now().date()
# Excel日期格式多样，需统一解析
def parse_excel_date(val):
    if isinstance(val, datetime): return val.date()
    if isinstance(val, str): return datetime.strptime(val, "%Y年%m月%d日").date()
    return None

overdue_days = (today - parse_excel_date(row[应收到期日])).days
```

#### 欠费合并计算

同一`单元号`的所有欠费记录合并：
1. 按费用类型分组统计
2. 本金 + 滞纳金（如有）
3. 生成合并通知一次性发送

- `@企服助手 催缴检查`
- 企微群 `@催缴`

## 📦 模块三：合同续租预警 (Contract Renewal)

### 功能

1. **三级续租预警** — 90天/60天/30天提前标记
2. **企业画像分析** — 缴费准时率、满意度、成交率
3. **续租方案生成** — 根据企业价值评估生成差异化方案
4. **稳租策略** — A/B/C级客户差异化稳租方案

### 续租预警三级体系

| 级别 | 剩余天数 | 推送对象 | 操作 |
|------|---------|---------|------|
| 🚨 红色预警 | ≤30天 | @招商人员 @管家 | 立即跟进 |
| ⚠️ 黄色预警 | 31-60天 | @招商人员 | 准备续租方案 |
| 📢 绿色提醒 | 61-90天 | 管家 | 关注动向 |

### 客户价值评估算法

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 租金贡献 | 30% | ≥50万/年=30分，≥20万=20分，≥10万=15分，<10万=10分 |
| 企业资质 | 25% | 高新/上市=25分，科技/研发=20分，贸易/服务=15分，其他=10分 |
| 缴费准时率 | 20% | ≥95%=20分，≥90%=15分，≥80%=10分，<80%=5分 |
| 服务满意度 | 15% | ≥80%=15分，≥60%=10分，≥40%=5分，<40%=0分 |
| 成交贡献 | 10% | ≥30%=10分，≥20%=7分，≥10%=5分，<10%=0分 |

**总分 ≥80 = A级，≥60 = B级，<60 = C级**

### 续租方案决策矩阵

| 条件 | 方案类型 | 租金策略 | 优惠 |
|------|---------|---------|------|
| 价值等级A 或 (缴费率≥95% 且 满意度≥80%) | A：原条件续租 | 维持原价 | 续租3年享95折 |
| 价值等级B 或 成交率≥30% 或 缴费率≥90% | B：优惠续租 | 上涨3-5% | 续租2年享98折 |
| 其他 | C：市场化续租 | 市场价 | 无 |

### 稳租策略（按价值等级）

**A级客户**（全方位稳租）：
- 提高服务标准：走访频率月度→双周，专属管家
- 关怀活动：生日礼物、节日慰问、企业周年庆贺
- 服务赠送：免费会议室8小时/月、免费停车券2张/月

**B级客户**（中度稳租）：
- 提高服务标准：走访频率季度→月度
- 关怀活动：节日慰问
- 服务赠送：免费会议室4小时/月

**C级客户**（基础稳租）：
- 基础服务标准
- 市场化租金定价

## 📦 模块七：走访计划管理 (Visit Management)

### 功能

1. **走访质量评分** — 基于客户情绪、成交情况、服务类别、详情记录完整性计算（满分100）
2. **走访闭环追踪** — 检查走访中提出的问题是否有后续跟进记录
3. **智能排程** — 根据企业等级、续租预警、欠费风险自动生成走访计划
4. **管家分配** — 根据单元号楼层自动分配管家

### 走访质量评分算法（满分100）

| 评分维度 | 权重 | 评分标准 |
|---------|------|---------|
| 客户情绪 | 40% | 满意=40分，一般=25分，不满意=10分 |
| 成交情况 | 30% | 成交=30分，成交金额>5000额外+10分 |
| 服务类别完整性 | 20% | 有服务类别=20分，无=0分 |
| 详情记录完整性 | 10% | ≥20字=10分，10-19字=5分，<10字=0分 |

### 智能排程规则

| 优先级 | 触发条件 |
|-------|---------|
| 高优先级（必访） | A级企业且上次走访>30天 / 续租剩余≤60天 / 有欠费风险标记 |
| 中优先级（应访） | B级企业且上次走访>90天 |
| 低优先级（可访） | C级企业 |

### 管家分配规则

| 管家 | 负责楼层 |
|------|---------|
| 戚亮先 | T1-6F、T1-7F、T1-8F |
| 刘瑞 | T1-9F、T1-10F、T1-11F |
| （可配置） | T1-12F及以上 |
